# Products API для занятия

Учебный Express.js API с SQLite, CRUD продуктов, Swagger и подготовленной JWT-авторизацией. Seed содержит 50 продуктов. Маршруты продуктов публичные — JWT для них пока не нужен.

## Требования

- Node.js 22.5 или новее (используется встроенный модуль `node:sqlite`)
- npm

## Установка и запуск

```bash
npm install
cp .env.example .env
npm run reset
npm run dev
```

Сервер откроется на порте из `.env` (сейчас `http://localhost:3010`), Swagger — на `http://localhost:3010/docs`. Swagger использует текущий адрес страницы, поэтому его запросы автоматически отправляются на правильный порт.

Фронтенд нужно запускать через HTTP-сервер (например, Vite), а не открывать HTML как `file://`. В адресе API обязательно указывать протокол:

```js
const API_URL = 'http://localhost:3000/api';
```

CORS разрешён для любых портов на `localhost` и `127.0.0.1` по HTTP/HTTPS. Заголовок `Authorization` для JWT также разрешён.

Для обычного запуска без автоматической перезагрузки:

```bash
npm start
```

Проверить API интеграционным тестом:

```bash
npm test
```

## Сброс и заполнение базы

Команда удаляет текущие продукты и пользователей, затем добавляет 50 демонстрационных продуктов:

```bash
npm run reset
```

SQLite-файл создаётся автоматически: `data/app.db`.

## Маршруты продуктов

| Метод | URL | Действие |
| --- | --- | --- |
| GET | `/api/products` | список продуктов |
| GET | `/api/products/:id` | один продукт |
| POST | `/api/products` | создать продукт |
| PUT | `/api/products/:id` | полностью заменить продукт |
| PATCH | `/api/products/:id` | частично изменить продукт |
| DELETE | `/api/products/:id` | удалить продукт |

Обязательные поля продукта: `name`, `price`, `description`. Seed использует ID 1–50, но новый продукт может иметь любой положительный целочисленный `id`, например 100. Если `id` не передать, сервер назначит следующий автоматически. Поля `image` и `discountPrice` необязательны: сервер автоматически создаст URL цветной SVG-картинки, а стоимость со скидкой приравняет к `price`.

Минимальный запрос создания:

```json
{
  "name": "Новый товар",
  "price": 1500,
  "description": "Описание нового товара"
}
```

### Список, фильтрация и пагинация

`GET /api/products` принимает параметры:

- `page` — страница, по умолчанию `1`;
- `limit` — элементов на странице от 1 до 50, по умолчанию `10`;
- `search` — поиск по имени и описанию;
- `minPrice` и `maxPrice` — диапазон обычной стоимости;
- `sortBy` — `id`, `name`, `price` или `discountPrice`;
- `order` — `asc` или `desc`.

Пример:

```http
GET /api/products?page=2&limit=10&search=кружка&minPrice=500&maxPrice=5000&sortBy=price&order=asc
```

Ответ содержит массив `items` и объект `pagination` с полями `page`, `limit`, `totalItems`, `totalPages`.

## JWT-авторизация (для следующего занятия)

| Метод | URL | Действие |
| --- | --- | --- |
| POST | `/api/auth/register` | регистрация |
| POST | `/api/auth/login` | вход и получение JWT |
| GET | `/api/auth/me` | данные текущего пользователя |

Для `/api/auth/me` передайте заголовок:

```text
Authorization: Bearer <token>
```

Перед реальным использованием замените `JWT_SECRET` в `.env` на длинную случайную строку.
